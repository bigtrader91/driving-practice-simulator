# Desktop control reference

The default layout keeps continuous driving actions under the left hand and reserves the right hand for the steering wheel.

| Action | Default |
|---|---:|
| Accelerator | W |
| Foot brake | S |
| Left / right indicator | A / D |
| Left / right mirror and shoulder check | Q / E |
| Rear-view mirror | R |
| Hazard lights | Z |
| Parking brake | Space |
| Horn | X |
| P / R / N / D | 1 / 2 / 3 / 4 |
| Camera / trajectory / width guide | C / T / V |
| Reset / HUD | F / H |

## Steering

Steering is intentionally not mapped to keyboard arrows. Press and hold the primary mouse button on the displayed wheel, then move around its centre as though rotating a physical wheel. One complete circular drag produces approximately one turn, with a hard stop at 1.5 turns in either direction. Releasing the mouse does not snap the wheel to centre; road-speed-dependent self-aligning torque returns it progressively while the vehicle moves.

## Pedals and transmission

W always represents accelerator pressure and S always represents foot-brake pressure. In D the accelerator produces forward motion; in R it produces reverse motion. P, R and D can be selected only while nearly stationary with the foot brake held. N can be selected only while nearly stationary.

## Remapping

Select a control in Settings and press its new key. When that key is already assigned, the two assignments swap, preserving a one-action-per-key layout. Bindings persist in browser storage.
