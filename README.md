# DrivePrep 3D — 한국형 운전 연습 시뮬레이터

React와 Three.js로 만든 초보 운전자·운전면허 준비생용 웹 운전 연습 시뮬레이터입니다. 실제 차량을 대체하는 공학용 물리 시뮬레이터가 아니라 **조작 순서, 차폭감, 핸들 되감기, 미러 확인, 방향지시등 절차를 반복 학습하는 교육용 도구**입니다.

## 핵심 조작

### 실제 핸들에 가까운 마우스 조향

- 화면의 핸들을 **마우스 왼쪽 버튼으로 잡고 있는 동안에만** 조향됩니다.
- 화면상 마우스 위치를 따라 즉시 꺾이는 방식이 아니라 핸들 둘레를 원형으로 드래그해 누적 회전합니다.
- 승용차 기준 중앙에서 좌우 각각 최대 약 **1.5바퀴(±540°)**를 지원합니다.
- 차종별 조향비로 핸들각을 앞바퀴 조향각으로 변환합니다.
- 정지 중에는 핸들이 임의로 중앙으로 돌아오지 않으며, 주행 중에는 속도에 비례한 복원력이 작동합니다.

### 왼손 키보드 기본 배치

| 기능 | 기본 키 | 기능 | 기본 키 |
|---|---:|---|---:|
| 엑셀 | `W` | 풋브레이크 | `S` |
| 좌·우 방향지시등 | `A` / `D` | 비상등 | `Z` |
| 좌·우 미러 확인 | `Q` / `E` | 룸미러 | `R` |
| P/R/N/D | `1` / `2` / `3` / `4` | 주차브레이크 | `Space` |
| 경적 | `X` | 시점 전환 | `C` |
| 궤적선 | `T` | 차폭선 | `V` |
| 시작 위치 복귀 | `F` | HUD 표시 | `H` |

`W`는 D단과 R단 모두에서 항상 엑셀이고 `S`는 항상 풋브레이크입니다. 차량 진행 방향은 D/R 기어가 결정합니다. P/R/D 변속은 차량이 거의 정지하고 풋브레이크를 밟은 상태에서만 허용됩니다.

설정 화면에서 모든 키를 다시 지정할 수 있습니다. 새 키가 이미 다른 기능에 사용 중이면 두 기능의 키가 자동으로 교환되며 설정은 브라우저 `localStorage`에 저장됩니다.

## 화면과 카메라

- 주행 화면을 가리던 대형 검은 패널을 없애고 가장자리의 작은 반투명 HUD로 재구성했습니다.
- 운전석, 보닛, 추적, 탑뷰를 지원합니다.
- 카메라 롤은 고정 0°, 편안함 약 ±1.25°, 현실감 약 ±1.72° 이내로 제한되어 화면이 90°·180° 뒤집히지 않습니다.
- 시야각, 좌석 높이와 앞뒤 위치, 미러 표시 방식·크기, HUD 크기를 조정할 수 있습니다.
- 사이드미러는 자동 모드에서 방향지시등 또는 미러 확인 중에 나타나며 R단에서는 후방카메라와 거리 가이드가 표시됩니다.

## 차량 거동과 평가

- 저속 크리프, 엑셀·브레이크 압력 램프, 주차브레이크와 기어 인터록을 지원합니다.
- 충돌 시 차량을 튕기거나 뒤집지 않고 마지막 안전 위치로 되돌린 뒤 정지합니다.
- 제한속도, 적색·황색 신호, 차선 변경 전 방향지시등·미러 확인, 가속하는 뒤차 앞 진입을 평가합니다.
- 전후방 근접 센서, 엔진음, 방향지시등, 경적, 충돌음, 성공음과 한국어 음성 코칭을 제공합니다.

## 연습 모드

1. 기본 조작과 출발·정지
2. 차폭감과 좁은 길
3. S자 곡선 코스
4. 직각(T자) 코스
5. 장내 기능시험 종합
6. 후진 주차
7. 평행 주차
8. 시내 차선 변경
9. 종합 도로주행 — 신호·정지선·횡단보도·어린이보호구역
10. 다차로 고속화도로 — 양보 차량과 가속 차량 판단

각 코스는 별도의 출발 위치, 제한속도, 목표 구역, 장애물과 평가 조건을 가집니다.

## 실행

```bash
npm ci
npm run dev
```

프로덕션 빌드와 핵심 불변조건 검증:

```bash
npm run check
```

## 기술 스택

- React 19 + TypeScript + Vite
- Three.js / WebGL
- Tailwind CSS + 일반 CSS
- Web Audio API와 브라우저 한국어 음성 합성

## 주의

실제 운전면허 시험 채점이나 도로교통법 판단의 최종 근거로 사용하지 마세요. 실제 차량 연습은 반드시 자격을 갖춘 지도자와 안전한 환경에서 진행해야 합니다.
